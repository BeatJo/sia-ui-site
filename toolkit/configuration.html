Configuration globale et formatage ​

Posez SiaProvider à la racine de l'application web et appelez configureFormats au démarrage. Le provider gère les textes, le thème et les valeurs par défaut des composants. configureFormats règle les fonctions de formatage, y compris celles appelées hors de React.

Une configuration de départ ​

tsx
import { SiaProvider } from "@sia-ui/react";
import { FRENCH } from "@sia-ui/headless";
import { configureFormats } from "@sia-ui/utils";
import "@sia-ui/react-web/styles.css";

// Une fois, au démarrage ; pas pendant le rendu d'un composant.
configureFormats({
  locale: "fr-CM",
  currency: "XAF",
  timeZone: "Africa/Douala",
  hour12: false,
  empty: "—",
});

export function Application() {
  return (
    <SiaProvider
      defaultColorMode="system"
      storageKey="mon-app.color-mode"
      locale={{ ...FRENCH, language: "fr-CM" }}
      defaults={{ button: { size: "sm" } }}
    >
      <App />
    </SiaProvider>
  );
}

App représente votre application. La feuille de style suppose que @sia-ui/react-web est installé ; elle accompagne les composants web. Les paquets du socle s'installent selon les besoins décrits dans la vue d'ensemble.

La devise et le fuseau ne sont pas des props de SiaProvider. Ils se règlent avec configureFormats. La langue du provider se passe dans locale.language, et non dans une prop language directe.

Les propriétés de SiaProvider ​

Le provider web est exporté par @sia-ui/react.

PropriétéRôleExemple ou défaut
childrenApplication ou section concernéeVotre arbre React
localeLibellés partiels et langue des formats ReactFRENCH, ENGLISH, { language: "fr-CM" } ; libellés français sans réglage
defaultsProps par défaut, indexées par clé de composant{ button: { size: "sm" } }
defaultColorModeMode initial si aucun choix n'est enregistré"light", "dark", "system" ; défaut "system"
colorModeMode contrôlé par l'application"dark"
onColorModeChangeNotification d'un changement de mode(mode) => setMode(mode)
storageKeyClé de persistance du mode, ou désactivation"sia-ui.color-mode" ; false pour désactiver

Les props passées directement à un composant gagnent sur defaults. Les clés acceptées et leurs propriétés sont précisées dans Valeurs par défaut des composants. SiaConfigProvider est déprécié ; utilisez SiaProvider pour une nouvelle intégration web.

Tous les réglages de configureFormats ​

ts
import { configureFormats } from "@sia-ui/utils";

configureFormats({
  locale: "fr-CM",
  currency: "XAF",
  dateLocale: "fr-CM",
  timeZone: "Africa/Douala",
  hour12: false,
  empty: "—",
  minusSign: "unicode",
  decimalSeparator: ",",
  groupSeparator: " ",
});
OptionEffetDéfaut
localeLangue des nombres, montants et utilitaires localisés"fr-FR"
currencyDevise de formatCurrency"XAF"
dateLocaleLangue des dates lorsqu'elle diffère de celle des nombreslocale
timeZoneFuseau des formateurs de dates qui l'acceptentCelui du poste
hour12Affichage des heures sur 12 ou 24 heuresUsage de la langue des dates
emptyRepli des formateurs pour une valeur absente ou invalide"—"
minusSign"unicode" pour −, "ascii" pour -"unicode"
decimalSeparatorSéparateur décimal à l'affichage et à la lectureSelon la langue
groupSeparatorSéparateur de milliers à l'affichage et à la lectureSelon la langue

Un appel ne remplace que les options fournies. getFormatDefaults() lit les valeurs en vigueur ; resetFormatDefaults() rétablit les valeurs initiales, notamment pour les tests. subscribeFormatDefaults(listener) permet de suivre les changements et rend une fonction de désabonnement.

Les réglages sont globaux au runtime JavaScript, partagés entre les sous-modules du paquet. Pour un serveur qui traite plusieurs utilisateurs, passez les options propres à chaque requête à l'appel ; ne changez pas ces valeurs globales pour chaque utilisateur.

Utiliser les formats dans et hors de React ​

Dans un service, un export ou un calcul, appelez directement les utilitaires :

ts
import { formatCurrency, formatDate, formatNumber, toNumber } from "@sia-ui/utils";

formatCurrency(4500); // XAF, selon la configuration globale
formatCurrency(12.5, { currency: "EUR", locale: "fr-FR" });
formatDate(null); // "—"
formatNumber(1234.5); // "1 234,5" avec les séparateurs configurés ci-dessus
toNumber("1 234,5"); // 1234.5

Dans un composant, useFormat() tient aussi compte de la langue du provider le plus proche et déclenche un nouveau rendu quand la configuration change :

tsx
import { useFormat } from "@sia-ui/headless";

export function LibelleMontant({ montant }: { montant: number | null }) {
  const f = useFormat();
  return f.formatCurrency(montant, { symbol: "short" });
}

Le hook expose formatCurrency, formatAmount, formatNumber, formatPercent, formatDate, formatDateTime, formatDateRange, formatRelativeDate, formatTimeAgo, toNumber et parseCurrency, ainsi que locale, dateLocale, currency et timeZone.

Les composants SIA qui consomment ces réglages, notamment les montants et sélecteurs de dates, en bénéficient aussi. Une chaîne déjà calculée par formatCurrency() hors de React ne se recalcule pas seule : c'est le rôle du hook dans un rendu.

Quelle configuration gagne ? ​

Pour la langue dans React, l'ordre est : option explicite, puis locale.language d'un provider, puis configureFormats (dateLocale pour les dates, sinon locale). Les autres réglages de formats viennent de configureFormats et cèdent aux options explicites.

Conséquences concrètes :

  • Avec locale={ENGLISH}, useFormat et les composants suivent l'anglais, même si configureFormats({ locale: "fr-CM" }) a été appelé.
  • Sans langue explicite dans les providers, dateLocale: "en-GB" peut donner des dates anglaises tout en conservant des montants français. Les libellés des composants gardent leur locale de textes, française par défaut.
  • Un appel direct à formatCurrency() ne lit pas le contexte React : il suit configureFormats ou ses propres options.

Adapter une section sans répéter toute la configuration ​

tsx
<SiaProvider locale={FRENCH} defaultColorMode="system">
  <App />
  <SiaProvider locale={ENGLISH} defaults={{ button: { size: "sm" } }}>
    <ApercuAnglais />
  </SiaProvider>
</SiaProvider>

FRENCH et ENGLISH s'importent de @sia-ui/headless. Le provider interne fusionne les textes et les valeurs par défaut avec ceux du parent. Il peut aussi forcer un mode light ou dark sur sa section. Sans theme, colorMode ni className, il n'ajoute pas de conteneur DOM.

Cette imbrication ne rend pas configureFormats local à une section : une devise différente se passe à l'appel ou via la prop dédiée du composant.

Pour changer de mode, utilisez useColorMode() de @sia-ui/react et ses méthodes setColorMode ou toggleColorMode. Voir Hooks et mode de couleur. Pour remplacer les textes, voir Langues et libellés.
