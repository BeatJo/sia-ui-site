Catalogue des utilitaires ​

@sia-ui/utils rassemble les fonctions réutilisables hors de React, dans les composants, les services ou les scripts. Ce catalogue présente les modules publics par besoin. Pour le provider, les réglages globaux et les priorités des formats, voir Configuration globale et formatage.

Importer ce dont on a besoin ​

ts
import { formatCurrency, groupBy, normalizePhone } from "@sia-ui/utils";
// Ou un module précis :
import { formatDate } from "@sia-ui/utils/date";
// Les règles de validation s'importent toujours depuis leur module :
import { createValidator, required } from "@sia-ui/utils/validation";

validation est volontairement absent de l'export racine : les noms min, max, email ou required gardent ainsi leur contexte. Les autres modules ci-dessous sont accessibles à la racine et par leur sous-chemin @sia-ui/utils/<module>.

Les formateurs monétaires s'appuient sur Intl.NumberFormat. Les devises sans décimales telles que XAF ou XOF s'affichent à l'unité. symbol: "short" convient aux colonnes compactes. Les conversions majorToMinor et minorToMajor prennent un nombre de décimales explicite si le défaut de deux ne convient pas. Voir Utilitaires partagés.

ts
import { compact, groupBy, maskMiddle } from "@sia-ui/utils";

compact([0, null, false, undefined, ""]); // [0, false, ""]
groupBy([{ statut: "paye", montant: 4500 }], (ligne) => ligne.statut);
maskMiddle("+237699112233", {
  visibleStart: 4,
  visibleEnd: 2,
  maskLength: 4,
  maskChar: "•",
}); // "+237••••33"

diffLines produit des données equal, added et removed, à rendre comme texte. Il ne produit ni HTML ni composant de comparaison. Ses limites de taille sont expliquées dans Utilitaires opérationnels.

URL, délais et attente ​

ModuleFonctionsUsage
querytoQueryString, fromQueryString, removeEmptyParams, mergeSearchParamsSérialiser et combiner des paramètres d'URL
asyncsleep, debounce, throttle, createRetry, toAsyncStateAttendre, différer, limiter et représenter une opération
pollpollUntil, documentVisibilitySource, PollTimeoutErrorAttendre un résultat terminal, avec échéance et annulation
ts
import { toQueryString, pollUntil } from "@sia-ui/utils";

toQueryString({ page: 1, actif: false, recherche: undefined });
// "?page=1&actif=false"

const controller = new AbortController();
// readTask est la fonction de lecture HTTP fournie par votre application.
const resultat = await pollUntil((signal) => readTask("42", signal), {
  isDone: (task) => task.done,
  intervalMs: 1000,
  timeoutMs: 60000,
  signal: controller.signal,
});

La boucle ne chevauche pas les requêtes. Une erreur de lecture termine l'attente ; la politique de retry HTTP reste celle du client. documentVisibilitySource est un adaptateur web explicite ; sur mobile, fournissez une source de visibilité adaptée. Voir Temps réel et attente.

Validation ​

API de @sia-ui/utils/validationUsage
isEmail, isUrl, isPhone, isSlug, isHexColor, isValidDate, patternsVérifier une valeur ou réutiliser un motif
required, minLength, maxLength, min, max, matchesDéclarer une contrainte de champ
email, url, phone, oneOf, sameAsComposer des règles de format, choix et correspondance
all, createValidatorAssembler des règles et un validateur de formulaire
ts
import { createValidator, required, email } from "@sia-ui/utils/validation";

const validate = createValidator<{ courriel: string }>({
  courriel: [required(), email()],
});
validate({ courriel: "" }); // { courriel: "Ce champ est obligatoire" }

Une règle retourne un message ou undefined. Un champ vide facultatif passe les règles de format ; required décide si le vide est interdit. Le validateur se branche sur useLocalForm : voir Formulaires.

Les contrôles côté client facilitent la saisie ; le serveur doit valider les fichiers reçus. Les opérations DOM ne constituent pas une API de fichiers native. copyText retourne un booléen et readText peut retourner null : prévoir le retour d'échec dans l'interface.

Téléphones et liens de navigation ​

ModuleAPIUsage
phonenormalizePhone, toNationalNumber, formatPhone, PHONE_COUNTRIESNormaliser et afficher selon une table de pays configurable

La table téléphonique livrée décrit le Cameroun ; aucune base mondiale n'est embarquée. La normalisation ne vérifie pas l'attribution réelle du numéro. navigationLinks construit des URL : l'application choisit comment les ouvrir et gère les permissions de géolocalisation si elle en a besoin.
