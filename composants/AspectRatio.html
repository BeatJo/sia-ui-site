AspectRatio ​

Une boîte au rapport imposé.

Elle existe pour une seule raison : réserver la place avant que l'image ou l'iframe n'arrive. Sans elle, le contenu qui suit saute au chargement — ce que mesure le Cumulative Layout Shift, et ce que les gens ressentent comme une page qui bouge sous le doigt.

Installation ​

bash
sia-ui add aspect-ratio

Ou par le paquet, sans rien copier :

tsx
import { AspectRatio } from "@sia-ui/react-web";
