RichTextEditor ​

Une saisie de texte mis en forme.

Elle rend du HTML, pas une structure à elle : ce qui sort se stocke, se renvoie et s'affiche partout ailleurs sans qu'un convertisseur soit nécessaire.

Installation ​

bash
sia-ui add rich-text-editor

Ou par le paquet, sans rien copier :

tsx
import { RichTextEditor } from "@sia-ui/react-web";
