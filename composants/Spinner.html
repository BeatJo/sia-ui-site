Spinner ​

Une attente sans durée connue.

Quand la durée est connue, une barre de progression en dit plus. Le ton current reprend la couleur du texte environnant : un indicateur posé dans un bouton doit suivre la couleur du bouton, pas celle du thème.

Installation ​

bash
sia-ui add spinner

Ou par le paquet, sans rien copier :

tsx
import { Spinner } from "@sia-ui/react-web";
