Référence des composants ​

Une page par composant : ce qu'il fait, comment l'installer, et toutes ses props avec leur type et leur valeur par défaut.

Ces pages sont écrites par le code. Les props viennent des types, les descriptions de leurs commentaires, la commande d'installation du registre. Aucune n'est recopiée à la main, donc aucune ne peut vieillir sans que le code vieillisse avec elle.

Pour voir un composant vivant — ses états, ses variantes, un bac à sable — le catalogue le montre. Pour le voir en situation dans un écran complet, la démonstration.
