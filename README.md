# SIA UI

Ce dépôt public sert le site, la documentation, le catalogue Storybook, la
démonstration et le registre HTTP de SIA UI.

- Documentation : https://beatjo.github.io/sia-ui-site/
- Catalogue : https://beatjo.github.io/sia-ui-site/storybook/
- Démonstration : https://beatjo.github.io/sia-ui-site/preview/
- Registre CLI : https://beatjo.github.io/sia-ui-site/r/v1/

Le code source principal est privé pour le moment. Ce dépôt public sert de
zone de contribution visible : bugs, demandes de composants, retours sur la
documentation et questions d'usage.

## Contribuer

Ouvre une issue avec le gabarit adapté :

- **Anomalie** pour un bug de composant, de paquet npm, de registre ou de CLI.
- **Composant ou variante** pour demander une nouvelle entrée ou un nouveau cas.
- **Documentation** pour une page confuse, un exemple cassé ou un lien mort.

Les contributions directes au code des packages se font sur invitation dans le
dépôt source privé.

## Paquets

Les paquets sont publiés sous le scope `@sia-ui` sur npm. Le dépôt public
reçoit les retours; les corrections sont faites dans le dépôt source, puis
publiées sur npm et sur ce site.
